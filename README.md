This is a branch specific to the reproducibility of the rover design paper.

You could directly obtain the data from the `rover_performance.data.csv` file.

To re-generate the data (and verify the reproducibility yourself), do this:

- Build the project like you normally do with DEM-Engine, as this branch has two new demos that are used to generate rover design data.

- Run DEMdemo_GRCPrep_Part1 and DEMdemo_GRCPrep_Part2, then make sure the generated `GRC_3e6.csv` files is copied to the (top of) build directory.

- Create a new conda environment and do the following:

```
conda install -c conda-forge pygalmesh conda install -c conda-forge trimesh
```

Then copy all `.py` files into your build folder.

- Copy the `wheel_slip.sh` file also into your build folder, as it is the script that automates the data generation.

- Run the `wheel_slip.sh` file from the (top of) build directory. Note this is written for running on clusters, but you should update it so it runs on your system. The output of the run is your raw data. Process the data to get something similar to the `rover_performance.data.csv` file I attached.

All data points are randomly generated, meaning you are free to run multiple instances of this `.sh` script, and combine the data generated by those instances. They are all independent of each other.
